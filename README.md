# Romeo & Juliet Web Project

Interactive web page based on William Shakespeare's play  
**"Romeo and Juliet" — Prologue and Act I Scene I**

## Features
- Semantic HTML layout
- Styled title page
- Navigation between Prologue and Scene I
- Interactive dialogue:
  - Hide/Show character lines
  - Highlight by character
  - Random quote generator
- Search in text
- Role filter
- Dark mode (with localStorage)
- Scroll progress bar (IntersectionObserver)
- Responsive UI
